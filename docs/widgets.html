01 / ПОДГОТОВКА

Установи Scriptable

Это отдельное приложение, которое будет показывать виджет Daylane на экране «Домой».

Открыть Scriptable в App Store
  1. В Daylane подключи синхронизацию GitHub и дождись надписи «Сохранено в облаке». Виджет показывает данные, уже отправленные в облако.
  2. Для виджета создай отдельный ключ GitHub: Only select repositories → daylane-data → Contents: Read-only. Он нужен только для чтения.

Виджет читает твой закрытый файл планера. Дневник и фотографии в нём не отображаются. Ключ вводится в Scriptable и хранится в его защищённом хранилище; сюда или в чат его присылать не нужно.

02 / ПОДКЛЮЧЕНИЕ

Добавь сценарий Daylane

  1. Открой эту страницу в Safari на iPhone или iPad и нажми «Скопировать сценарий».
  2. В Scriptable нажми ＋, вставь скопированное содержимое в редактор и назови сценарий Daylane.
  3. Нажми ▶︎, вставь ключ GitHub в появившееся поле и нажми «Подключить».
  4. Выбери предпросмотр: дела, привычки или «На полях».

03 / ЭКРАН ДОМОЙ

Добавь виджет

  1. Зажми свободное место на экране «Домой» → «Изменить» → «Добавить виджет» (в некоторых версиях — кнопка ＋).
  2. Найди Scriptable, выбери размер и добавь виджет.
  3. Зажми новый виджет → «Изменить виджет». В Script выбери Daylane.
  4. В поле Parameter укажи: today — дела, habits — привычки, queue — «На полях». Поле можно оставить пустым для дел на сегодня.

Можно добавить три отдельных виджета. Те же шаги работают на iPad; сценарий и ключ нужно настроить на каждом устройстве.

НАПОМИНАНИЯ ПРИ ЗАКРЫТОМ DAYLANE

Передай напоминания телефону

Scriptable может заранее назначить системные уведомления. Они могут приходить, даже когда Daylane и Scriptable закрыты. Mac и отдельный сервер не нужны.

  1. Если сценарий Daylane уже установлен, замени его содержимое свежим кодом с этой страницы. Сохранённый ключ останется на устройстве.
  2. У нужных дел в Daylane выбери «Напомнить», например за 10 минут. Дождись «Сохранено в облаке».
  3. В Scriptable запусти Daylane → Напоминания телефона → Включить напоминания.
  4. В настройках iPhone/iPad разреши уведомления для Scriptable. Для проверки выбери «Проверить уведомление»: оно назначается через 10 секунд.

Обновляй после изменений. Загружаются до 40 ближайших напоминаний в пределах 14 дней. После переноса, отмены или выполнения задачи снова запусти Daylane → Напоминания телефона → Обновить напоминания, иначе старое уведомление может остаться. Обновляй список и не реже раза в неделю, чтобы добавлялись будущие повторы.

Виджет тоже обновляет уведомления при загрузке, если они включены, но iOS сама определяет время обновления. Это не мгновенная фоновая синхронизация. При отсутствии связи ранее назначенные уведомления продолжают ждать своего времени.

Уведомления приходят от Scriptable. Режим «Фокусирование», сводка уведомлений, звук и системные разрешения влияют на их показ. На твоём iPhone/iPad доставка ещё не проверена. Отключить ожидающие уведомления можно в том же меню; другие сценарии Scriptable не затрагиваются.

Как обновляются данные

Виджет запрашивает обновление примерно через 30 минут, но точное время определяет iOS/iPadOS. Для свежего предпросмотра запусти Daylane в Scriptable. Без связи показывается последняя сохранённая копия с отметкой; если это другой день, виджет укажет дату копии.

Нажатие на виджет открывает соответствующий раздел Daylane. Изменять дела и отмечать привычки нужно в планере.

Для смены ключа или отключения виджета запусти сценарий Daylane в Scriptable и выбери нужный пункт. Сама установка на твоём iPhone/iPad ещё требует этих шагов; работа на реальном устройстве здесь не проверялась.
